# Board + My Tasks — design overrides

Source: UI/UX Pro Max Soft UI / Micro-interactions + TaskFlow teal tokens.

## Scope

Visual/layout only. Do **not** change:
- Board: drag/drop, status updates, filters, permissions, create modal wiring
- My Tasks: tabs, filters, complete/review flows, import/export, bucket rules

## Direction

- Soft UI teal atmosphere; Plus Jakarta Sans
- Board: no emoji columns; accent rails; `card-premium` cards; title-first hierarchy
- My Tasks: Soft KPI band; segmented tabs; section-tinted overdue/today/upcoming/done
- Motion: rise + stagger; respect reduced-motion
- No purple glow, no emoji icons as status
